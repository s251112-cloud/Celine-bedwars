# 🛏️ 3D Mini-BedWars (Web Edition)

A lightweight, browser-based **3D Mini-BedWars game** built with JavaScript and **Three.js**. Experience classic BedWars mechanics—explore your sky island, guard your base, and destroy the enemy bed directly in your browser!

## ✨ Features

- 🎮 **3D First-Person Perspective (FPS):** Immersive Pointer Lock controls for smooth looking and moving.
- 🏝️ **Floating Sky Island:** Rendered with real-time directional lighting, shadows, and fog effects.
- 🛏️ **Interactive Bed Mechanic:** Approach the enemy bed and left-click to destroy it!
- ⚡ **Zero Installation:** Runs 100% in any modern web browser—no plugins or downloads needed.

---

## 🎮 How to Play

### Controls
| Key / Action | Function |
| :--- | :--- |
| **W, A, S, D** | Move Forward / Left / Backward / Right |
| **SPACE** | Jump |
| **MOUSE** | Look Around |
| **LEFT CLICK** | Break Bed / Interact |

### Objective
1. Click anywhere on the screen to enable **First-Person Controls**.
2. Walk up to the **Red Bed**.
3. Left-click on the bed when you are close enough to **destroy it** and win the game!

---

## 🛠️ Tech Stack

- **HTML5 & CSS3:** Responsive UI overlays and game canvas styling.
- **JavaScript (ES6+):** Physics calculation, movement collision, and game logic.
- **[Three.js](https://threejs.org/):** WebGL 3D rendering engine for scene lighting, camera, and geometries.
